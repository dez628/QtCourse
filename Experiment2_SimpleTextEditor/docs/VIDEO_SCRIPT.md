# 实验 2 演示视频录制脚本

建议时长：3 至 4 分钟。录制时先启动程序，保持窗口清晰可见。

1. **0:00-0:20 主界面**
   - 展示文件、编辑、格式、查看、帮助菜单。
   - 展示三组工具栏、行号和状态栏。
   - 说明程序使用 Qt Widgets、Qt Designer、Action 和自定义 CodeEditor。

2. **0:20-0:45 新建与保存**
   - 新建文档，输入 `Qt 文本编辑器演示` 和多行中文。
   - 指出标题出现 `*`。
   - 保存为 `演示文本.txt`，指出星号消失。
   - 再次修改并保存，证明当前文件路径可用。

3. **0:45-1:05 打开与异常处理**
   - 新建空白文档，再打开刚才的文本，确认内容恢复。
   - 打开任意非文本文件，例如
     `C:\Windows\System32\notepad.exe`，展示“无法打开”提示。

4. **1:05-1:30 编辑与 Action 状态**
   - 选中部分文字，展示剪切、复制可用。
   - 执行复制、粘贴。
   - 执行撤销、重做。
   - 取消选区，展示剪切、复制自动变灰。

5. **1:30-1:55 格式和行号**
   - 调整字号。
   - 选中文字设置字体颜色和文字背景色。
   - 修改编辑器背景色。
   - 切换自动换行和显示行号。

6. **1:55-2:25 查找与替换**
   - 打开查找，演示连续查找、区分大小写和未找到提示。
   - 打开替换，执行一次替换。
   - 执行全部替换，随后用一次撤销恢复全部内容。

7. **2:25-2:50 未保存保护与自动保存**
   - 修改已保存文件，点击关闭或新建。
   - 分别展示“取消”和“保存”两种选择。
   - 开启每 10 秒自动保存，修改文字后等待标记消失。

8. **2:50-3:10 关于与 Git**
   - 按 F1 打开关于对话框。
   - 切换到终端执行 `git log --oneline -5`，展示实验 2 的提交记录。

录制完成后，将视频另存为：

`docs/demo/实验2-简单文本编辑器演示.mp4`
